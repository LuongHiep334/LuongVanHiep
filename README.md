## 🚀 Dự án nổi bật

### 1. SMASH-VN – Website kinh doanh sản phẩm cầu lông
*Đồ án tốt nghiệp · 06/2026 – 09/2026 · Làm việc nhóm · Vai trò: thành viên phát triển website*

Website hỗ trợ **mua hàng trực tuyến**, **bán hàng tại quầy (POS)** và **quản trị sản phẩm, đơn hàng, tồn kho**. Quản lý và nhân viên dùng chung một hệ thống.

- **Công nghệ:** Java, Spring Boot, Spring Data JPA, SQL Server, Thymeleaf, HTML/CSS, JavaScript, Bootstrap, Git/GitHub
- **Triển khai:** chạy trên VPS Ubuntu, SQL Server chạy bằng Docker, ứng dụng chạy dạng systemd service
- 🔗 **Source code:** [github.com/LuongHiep334/SMASH-VN_Shop-ban-dung-cu-cau-long](https://github.com/LuongHiep334/SMASH-VN_Shop-ban-dung-cu-cau-long)
- 🌐 **Demo:** [http://103.249.117.202:45357](http://103.249.117.202:45357)
- **Đóng góp của tôi:**
  - Xây dựng chức năng đăng ký, đăng nhập và phân quyền cho khách hàng
  - Xây dựng trang quản lý tài khoản khách hàng: sổ địa chỉ, theo dõi và quản lý đơn hàng
  - Tích hợp API đơn vị vận chuyển vào quy trình đặt hàng
  - Phân tích và xây dựng cơ chế **polling** để cập nhật trạng thái đơn, thay cho webhook vì môi trường chạy local không nhận được callback từ bên ngoài
  - Phân tích, thiết kế giao diện trang quản trị
  - Xây dựng giỏ hàng và các trải nghiệm người dùng phía khách hàng
  - Cách làm việc: tự phân tích yêu cầu, sử dụng AI agent hỗ trợ lập trình, sau đó kiểm tra và tích hợp vào hệ thống

### 2. Net Manager – Phần mềm quản lý quán net
*06/2025 – 08/2025 · Làm việc nhóm · Vai trò: Trưởng nhóm*

Ứng dụng desktop quản lý máy trạm, nhân viên, thực đơn, order, thanh toán và thống kê doanh thu.
